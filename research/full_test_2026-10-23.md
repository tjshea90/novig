## Tools added (they run on GitHub, free, every day)
- `cloud/StarCheckMain.kt` (`./gradlew :cloud:starcheck`): every graded engine line re-rated with the rating the app ships, by stars and by each input, CLV and ROI with intervals over games. In the daily digest.
- `tools/api_quality.py`: medians over the scans an API was ON (a part-time API was judged on its off scans), days covered, failing share, and a by-day table. In the daily digest.

## Found, not changed (with the reason)
- **Bid churn**: 95,000-123,000 postings a day for ~100 fills (about 1 per 1,000); 372,794 of the postings ended "About to expire: re-posted". The re-post from a fresher fair is a deliberate safety rule (a bid never outlives the fair it was priced from), and fills are 10x likelier 0-1 point under Novig's offer than 2-5 points under it. Changing it is a class B rule change; the volume loop in ROUTINE.md owns it.
- **pinnapi**: the one key on GitHub answers 403 (16 refusals today, retried hourly). Tj: replace or remove it (Settings › APIs).
- **The Odds API**: all 21 free keys are spent to 1 Nov; it fed 0 lines in 3 days. Harmless (no credits), but it adds nothing.
- **Unabated**: quotes 16.6 h old (p90), 9 points off Pinnacle, 0 lines fed in 3 days; the governor rests it.
- **BoltOdds**: the keys on GitHub are Free/Trial ("Free plan cannot access API"): failing in 87% of the engine's scans. The Growth key has not reached GitHub (CH76).
- **Per-API CLV attribution is not possible yet**: a line records the books behind its fair, not which API supplied each book. Follow-up FX6.
