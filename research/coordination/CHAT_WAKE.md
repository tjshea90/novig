# Chat wake: Tj's messages are seen within seconds, with no polling and no wasted usage (TCL70, Tj 2026-10-17, permanent)

**Why:** 2026-10-16 19:14 ET to 22:50 ET nobody answered the app chat: the 19:20 account's routine never ran, a stale interactive lease blocked a new session, and nothing woke anyone. Tj (chat t1792206180417): "my messages are seen within 30 seconds and responded to ... without usage being wasted ... maybe GitHub has a feature for this".

**The three layers (cheapest first)**
1. **A live session** runs `bash tools/chat_watch.sh` under Monitor (one `git ls-remote` every 6 s, zero model tokens until a message) and acks (`tell_tj.py chat-ack`, the 👍) within ~6 s. Monitor ends after about 30 minutes: re-arm it when the notice comes.
2. **GitHub wakes a sleeping account.** `chat-wake.yml` (source `tools/chat-wake/`, installed on the `cloud-config` branch because a push workflow runs from the pushed branch) fires on every push under `chat/`. `tools/chat_wake.py` waits 40 s; if Tj's message has no ack and no reply it writes a notice into the chat ("Waking acct-xxxxxx's Claude...") and POSTs that account's routine **API trigger** (`/fire`, https://code.claude.com/docs/en/routines): the on-duty account first (`rotation.py` slot), the others after it, accounts in `away.json` last. One wake per 10 minutes (the woken session reads every message). If nothing can be woken the notice says so in words (no link saved, usage out), so Tj sees why. Cost: GitHub minutes (free, public repo) and nothing from Claude while nobody writes; a woken routine is one session start, only when no live session answered.
3. **Any session** that starts reads `chat/` at once (resume.sh / `chat_watch.sh` print every unanswered message).

**Chat mode (what a woken or interactive session does):** answering chat NEVER needs the repo lease (it writes only `chat/` on `cloud-config`, not the repo). Start `chat_watch.sh` under Monitor, `chat-ack`/`chat-reply` each message, write a request into TASKS.md, then work only if the lease is free or Tj says "force". Stay while Tj writes (he has been idle under 20 minutes), then stop: an idle session costs nothing. A fire text starting `CHAT:` means chat mode.
