# CH73 audit: what the phone runs while the GitHub engine drives (2026-10-23)

Method: every use of `ScanSettings.cloudDrives` (the one predicate for "the engine is the scan") in app/ and data/.
Result: with Run on GitHub on (the default) the phone already stands down for:
- scan (`CloudScanner` via `SwitchingScanner`), sources list (VigilantApp: empty), Parlay/PropLine pulls, Novig socket and order socket warm-up, auto-bet (`AutoBettor` returns an empty report), BoltOdds/Kalshi/SX sockets while live is on GitHub (`phoneSockets`/`phoneLive`), CNO (served by the engine's `cno.json.gz`), bids (desk runs on the engine when `engineBids`).
- Phone keeps only: settings out, ETag polling of status/feed/trades/desk/usage/messages/chat (`CloudLink` loops, 304s free), the Bet sheet's re-price at the tap, the Feed's 8-15 s requote of listed rows (phone's own Novig key), key handling and bid posting by hand.
Phone mode (Run on GitHub off): engine `on:false`, trading OFF, every cloud lane off (shipped in CH73 part 1).
Open (not leaks, moved on later versions): CH66b/c, CH72.
