# SX Bet settlement rules that matter for matching Novig lines (help.sx.bet, read 2026-10-18)

| sport | what counts | consequence for Vigilant |
| :- | :- | :- |
| NFL/NCAAF | Game and 2nd half INCLUDE overtime; 4th quarter excludes it; suspended after 55 min settles on the halted score; before 55 min refunded; rescheduled = cancelled | SX types 226 (12 incl. OT), 28 (O/U incl. OT), 342 (AH incl. OT) are Novig-equivalent; period lines (quarters) must not be matched to full-game lines |
| NBA/NCAAB/WNBA | Game and 2nd half include OT; 4th quarter excludes; minimum 43 min (NBA), 35 min (others) | same as above |
| NHL | Team and game bets include OVERTIME AND SHOOTOUT; player bets include OT, not the shootout; 3rd period excludes both; period must be played in full | matches Novig NHL game lines; period (type 21/45/46, 64/65/66, 202-204) are separate markets |
| MLB | Moneyline official after 5 innings (4.5 if home leads); total and run line after 9 (8.5); extra innings count; postponed/suspended >12 h voids pre-game game-period bets; listed pitchers are informational | type 52/226 ML and 2/28 totals match; the first-5-innings types 236, 281, 1618 are their own markets |
| Soccer | 90 minutes plus added time only (no extra time or penalties) except cup-winner futures; 1X2 has six bet types | 1X2 (type 1) is regulation; never match to a "to advance" line (type 88) |
| Tennis | Retirement after one full set keeps the match moneyline; set/handicap/total-games void if the match is unfinished | types 52/226 ML ok; 165/866/166/201 void on retirement |
| Player props | Settled on the full game incl. OT; player must start (NBA) or play a snap (NFL) | type 995 anytime TD scorer etc. |
Sources: https://help.sx.bet/en/articles/5090593 (football), 5090617 (basketball), 5090642 (hockey), 5090616 (baseball), 5090654 (soccer), 5090684 (tennis).
