# Which APIs are worth it (CH58, 2026-10-21) — framework now, numbers as the journal fills

**Data.** From this release the engine writes `apiq-<day>-run<id>.jsonl.gz` (one scorecard per API per finished scan: p90 quote age, distance from Pinnacle, answered %, lines it fed, lines it was the ONLY source of, role, budget left) to the `cloud-archive-*` Releases. Read it with `python3 -I tools/api_quality.py <downloaded files>`: KEEP = unique lines or fresh and close to Pinnacle; DROP-CANDIDATE = answers under half the time or feeds nothing and is not a paid plan; paid plans only ever get WATCH from the tool, a human decides. Add accuracy by CLV per source from `tools/clv_consensus.py` (CH57): where an API's close agrees with Pinnacle's.

**ParlayAPI websocket tier (question from Tj).** From PARLAY_API.md §1/§10: the odds WebSocket/SSE (`/ws/odds`, `/v1/sse/odds`) is **Business, $40/month, 1,000,000 credits**; Pro ($20) has no odds socket (it has 25 live play-by-play streams). It is worth buying only if all three hold, which the journal will show after a few days of data: (1) ParlayAPI is the SOLE source of a meaningful number of priced lines (`sole` column) or is the freshest feed for lines that become bets; (2) its pushed prices beat the current best feed's age on those lines (compare p90 age here with BoltOdds/Kalshi sockets, which are already free-ish); (3) its CLV against Pinnacle's close is as good as SGO's. Until then, no purchase: the sockets already held (BoltOdds, Kalshi, SX Bet) cover push odds, and the sharp fair comes from SGO/Pinnacle. Re-judge after 7 days of `apiq` data.
